# Telecom BSS API

Microsserviço responsável pela regra de negócio (BSS - Business Support System) de um provedor de telecomunicações, focado na gestão de clientes, planos de banda larga e controle de assinaturas.

## Tecnologias Utilizadas

* **Java 17+**
* **Spring Boot 3** (Web, Data JPA)
* **PostgreSQL** (via Docker)
* **Maven**
